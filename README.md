# プロジェクト名（九星気学 本命星・月命星算出アプリ）

## 本命星、月命星算出プロ暗く(JavaScript)
    - 誕生日を入力すると本命星と月命星を出力します。

### Folder Structure
    - kigaku_birthday.html
    - main.js
    - calenderdata.js
    - ninestars_lineup.js
    - honmei.js
    - getumei.js

### 🚀 機能
    - 誕生日を入力するとその誕生日に対応する本命星、月命星を返します。

### 🛠 使用技術
    - Node.js V24
    - VS Code

### 🏃 実行方法
    1. kigaku_birthday.htmlを実行してください。
    2. 生年月日を聞いてきますので入力すると本命星、月命星を返します。
    3. 月命星はカレンダーデータの引用元に従い、1912年～2065年までの間で使用できます。
